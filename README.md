# ar-cube

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

An AR cube project created with Three.js.

## Demo
Live demo: [https://code4fukui.github.io/ar-cube/](https://code4fukui.github.io/ar-cube/)

## Features
- Displays a cube-based scene that can be viewed in AR using a smartphone
- Allows users to interact with the cubes by selecting and moving them
- Uses a GLTF model for the cubes

## Requirements
- Web browser with WebXR support

## Usage
1. Open the [live demo](https://code4fukui.github.io/ar-cube/) in a compatible web browser on your smartphone.
2. Allow the browser to access the camera when prompted.
3. Move your phone around to view the AR cube scene.
4. Tap on the cubes to select and move them.
