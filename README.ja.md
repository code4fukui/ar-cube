# ar-cube

Three.jsで作成されたARキューブプロジェクト。

## デモ
ライブデモ: [https://code4fukui.github.io/ar-cube/](https://code4fukui.github.io/ar-cube/)

## 特徴
- スマートフォンを使用し、ARで閲覧可能なキューブベースのシーンを表示
- キューブを選択して移動させるなど、ユーザーによるインタラクションが可能
- キューブにGLTFモデルを使用

## 要件
- WebXRをサポートするWebブラウザ

## 使い方
1. スマートフォンの対応Webブラウザで[ライブデモ](https://code4fukui.github.io/ar-cube/)を開きます。
2. カメラへのアクセスを求められたら、許可します。
3. スマートフォンを動かして、ARキューブのシーンを見渡します。
4. キューブをタップして選択し、移動させます。
